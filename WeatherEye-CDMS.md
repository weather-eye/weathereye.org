WeatherEye uses SURFACE CDMS for it’s Climate Data Management System implementation primarily because SURFACE is a complete CDMS solution that is built using Python (Django) and TimescaleDB (PostgreSQL).

- Set up multiple user accounts
- Be configured for use in a specific country
- Manage metadata for station locations, equipment etc.
- Ingest data from multiple sources
- Perform quality control (QC) on data
- Create products
