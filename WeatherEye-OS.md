Install WeatherEye on dedicated server(s) by installing WeatherEye OS (WOS).

WOS is a customised version of the PROXMOX Debian operating system image that gives you a WeatherEye themed version of PROXMOX (for virtual machine creation and management) with [[WeatherEye Controller]] already installed and both PROXMOX and WXC interfaces accessible from the same Web UI.

Once the operating system is installed, [[WeatherEye Controller]] can be used to automatically provision virtual machines (VMs) and they orchestrate the WeatherEye application to these VMs.

WOS can be downloaded to memory stick and installed on physical server infrastructure.
